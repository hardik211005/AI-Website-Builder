🚀 AI Website Builder (SaaS)

An AI-powered SaaS platform to generate, customize, and deploy websites instantly — powered by a credit-based monetization system.

🌐 Live Demo

👉 https://ai-website-builder-woad.vercel.app/

📖 Description

AI Website Builder is a full-stack SaaS application that allows users to create websites using AI with minimal effort.

It includes a credit-based system where users purchase credits and each AI generation consumes credits dynamically — making it production-ready for real-world usage.

✨ Core Features
🤖 AI-powered website generation
🎨 Real-time editing & live preview
💳 Credit-based usage system (purchase + consumption logic)
🔐 Secure authentication (Better Auth)
💰 Stripe payment integration
⚡ Scalable backend architecture
📱 Fully responsive UI

🧠 How It Works
User signs up / logs in
Purchases credits via Stripe
Uses AI to generate websites
Credits are deducted progressively during generation
User can edit, preview, and deploy

🛠️ Tech Stack
Layer	Technology
Frontend	React.js
Backend	Node.js, Express.js
Database	Neon PostgreSQL
Auth	Better Auth
Payments	Stripe
Deployment	Vercel (Frontend), Render (Backend)
